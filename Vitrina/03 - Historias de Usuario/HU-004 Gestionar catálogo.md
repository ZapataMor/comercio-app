# HU-004 — Gestionar catálogo

> **Como** [[Comerciante]] **quiero** gestionar mi negocio, categorías y productos **para** que
> los clientes vean lo que ofrezco.

## ✅ Criterios de aceptación
- [x] Creo/edito mi negocio y lo abro/cierro (activo).
- [x] CRUD de categorías (nombre único por negocio).
- [x] CRUD de productos con [[Tipos de Venta]], disponibilidad y soft delete.
- [x] Solo veo/edito lo mío (aislamiento).
- [x] El catálogo soporta búsqueda, filtros y paginación.
