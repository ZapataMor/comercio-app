# Vitrina — Segundo cerebro de comercio-api

Vault de **Obsidian** con el conocimiento de **negocio y producto** de comercio-api
(el *porqué* y el *qué*). El *cómo* (código) vive en `../backend` y `../frontend`.

## Cómo abrirlo
1. Abre Obsidian → **Open folder as vault** → selecciona esta carpeta `Vitrina/`.
2. Empieza por [`00 - Inicio/🏠 Home.md`](<00 - Inicio/🏠 Home.md>).

## Estructura
- `00 - Inicio/` — Home (dashboard) y Estado Actual
- `01 - Negocio/` — pitch, propuesta de valor, modelo, lógica de negocio, glosario
- `02 - Actores/` — los 4 roles y su mapa
- `03 - Historias de Usuario/` — HU-xxx
- `04 - Casos de Uso/` — CU-xxx
- `05 - Casos de Prueba/` — CP-xxx
- `06 - Diseño/` — flujos, pantallas, sistema visual
- `07 - Convenciones/` — notas, negocio, tags
- `08 - Ideas/` — backlog conceptual
- `_templates/` — plantillas para notas nuevas

## Convenciones
Ver `07 - Convenciones/`. Notas atómicas, con frontmatter, enlazadas con `[[wikilinks]]` y a su
`_MOC`. Lo no confirmado se marca con `> [!todo]`, no se inventa.

## Plugins recomendados (opcional)
- **Templater** o Templates (apunta la carpeta de plantillas a `_templates/`)
- **Dataview** (para listar HU/CU/CP por estado desde el frontmatter)
